# Infinity Browser — Release Package

This directory contains the pre-compiled Android APK ready for GitHub Releases and testing.

## Files
- `InfinityBrowser.apk` — Production-ready debug APK for Android devices.
- `app-debug.apk` — Standard Gradle debug output artifact.

## Installation Instructions
1. Download `InfinityBrowser.apk` to your Android device (or transfer via USB / adb).
2. Open the file on your device and tap **Install** (allow installation from unknown sources if prompted).
3. Open **Infinity Browser** and experience lightning-fast, stripped-down web browsing.

## Direct ADB Command
```bash
adb install -r InfinityBrowser.apk
```
